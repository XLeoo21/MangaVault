1. Introduccio i objectiu de la fase

4. Configuracio de l'entorn i base de dades

Vaig configurar la connexio a MySQL a .env i .env.example. D'aquesta manera, qualsevol persona que cloni el projecte te una plantilla correcta. 

APP_NAME=MangaVault
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=mangavault
DB_USERNAME=root
DB_PASSWORD=

La base de dades real ha d'existir al teu servidor MySQL abans d'executar migracions en local.

5. Instal·lacio de Laravel Breeze (autenticacio)

Breeze aporta autenticacio llesta per fer servir (registre, inici de sessio, tancament de sessio, recuperacio de contrasenya, verificacio de correu i gestio del perfil). 

composer require laravel/breeze --dev
php artisan breeze:install blade --no-interaction

Els controladors d'autenticacio es generen automaticament a app/Http/Controllers/Auth.

VerifyEmailControllerVerificacio de correu

6. Disseny de la base de dades amb migracions

Vaig crear i ajustar migracions per representar l'estructura del domini MangaVault.

6.1 Taula mangas

$table->foreignId('user_id')->constrained()->cascadeOnDelete();
$table->string('title');
$table->string('author')->nullable();
$table->text('synopsis')->nullable();
$table->unsignedInteger('total_chapters')->nullable();

6.2 Taula genres

$table->string('name')->unique();

6.3 Taula pivot genre_manga

$table->foreignId('manga_id')->constrained()->cascadeOnDelete();
$table->foreignId('genre_id')->constrained()->cascadeOnDelete();
$table->primary(['manga_id', 'genre_id']);

6.4 Taula pivot manga_user

$table->foreignId('manga_id')->constrained()->cascadeOnDelete();
$table->foreignId('user_id')->constrained()->cascadeOnDelete();
$table->string('status')->default('plan_to_read');
$table->unsignedTinyInteger('rating')->nullable();
$table->unsignedInteger('current_chapter')->default(0);
$table->primary(['manga_id', 'user_id']);

6.5 Camp extra a users

$table->boolean('is_admin')->default(false);

Nota: es va ajustar l'ordre de timestamps de migracions per evitar conflictes de claus foranes en migrar.

7. Creacio de models i relacions Eloquent

Vaig preparar els models i les seves relacions per reflectir el domini, sense programar encara la logica de negoci.

7.1 Relacions del model User

  • mangas(): hasMany (mangas creats per l'usuari).
  • collectionMangas(): belongsToMany (col·leccio personal amb pivot extra).

7.2 Relacions del model Manga

  • user(): belongsTo.
  • genres(): belongsToMany.
  • users(): belongsToMany amb status, rating, current_chapter.

7.3 Relacions del model Genre

  • mangas(): belongsToMany.

8. Controladors i rutes (estructura MVC)

Vaig generar controladors resource i els vaig deixar amb metodes buits com a base de treball.

8.1 Controladors creats

php artisan make:controller MangaController --resource --model=Manga
php artisan make:controller GenreController --resource --model=Genre
php artisan make:controller CollectionController
php artisan make:controller UserController --resource --model=User

ProfileController ja ve generat per Breeze.

8.2 Rutes definides

Route::middleware('auth')->group(function () {
    Route::resource('mangas', MangaController::class);
    Route::resource('genres', GenreController::class);
    Route::resource('users', UserController::class);
    Route::get('/collections', [CollectionController::class, 'index'])
        ->name('collections.index');
});

require __DIR__.'/auth.php';

Amb aixo queda disponible tota l'estructura de navegacio per a la fase seguent.

9. Autoritzacio amb Gates i Policy

Vaig implementar un sistema de permisos basic i escalable.

9.1 Policy de Manga

Es va generar MangaPolicy per controlar permisos per recurs.

php artisan make:policy MangaPolicy --model=Manga

Regles aplicades:

  • is_admin: acces complet (override amb el metode before()).
  • is_owner: nomes el propietari pot editar/eliminar el seu manga.

9.2 Gates a AppServiceProvider

Gate::policy(Manga::class, MangaPolicy::class);
Gate::define('is_admin', fn (User $user) => $user->is_admin);
Gate::define('is_owner', fn (User $user, Manga $manga) => $user->id === $manga->user_id);

9.3 Enllac automatic al controlador

$this->authorizeResource(Manga::class, 'manga');
